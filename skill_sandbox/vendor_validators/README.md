# Reviewed upstream format validators

These unmodified skill-creator Python scripts were obtained from the official
OpenAI and Anthropic repositories at the immutable revisions in `manifest.json`.
Their Apache-2.0 licenses are retained next to each script. SHA-256 verification
precedes loading. They are run locally on complete frontmatter which first passed
Injecticide's bounded parser; no uploaded script is imported or executed.

They are reference format checks, not comprehensive security audits, live vendor
documentation verification, or guarantees that any product accepts a package.
Their results do not change governance decisions. Missing validators for other
products are reported as unavailable, never as a pass.

Upstream changes are monitored by Research MCP. A new executable revision must
be reviewed, pinned, hash-verified and tested through an application release;
the research worker cannot hot-load downloaded code.
