# Skill analysis leadership — implementation milestone

The lead's objective is superior analysis across agentic packages, with skills
the present focus and projects/plugins intended later. This milestone deepens
the analysis engine and establishes comparable evidence; it does not declare
Injecticide an industry standard or a benchmark winner.

## Selected mechanism

The released Python detector is explicitly intraprocedural. Actual 0.10.0
whole-package probes missed a credential getter and network sender connected by
local helper calls, while the corresponding public-argument control also had no
flow finding. Baseline hashes/results are preserved in
`tmp/skill-leadership-0-11/baseline-cross-file.json`.

Ishan's new bounded package effect analyzer resolves supported local imports,
arguments and returns and retains a physical source/call/sink witness. Unsupported
dispatch, recursion, dynamic imports and exhausted budgets remain explicit
boundaries. Existing findings are refined only at completely modeled matching
sites, with reconciliation evidence retained. No uploaded code is executed.
Elena's independent review challenges missed flows and false witnesses, including
constant returns, overwritten APIs, selected container members and file identity.

The research memos identify primary program-analysis references, recent published
research, inspectable implementation choices and remaining cross-domain command-
argument limitations. Research-reported scores are not Injecticide measurements.

## External evaluation

The new offline evaluator preserves source revisions, original artifact hashes,
label authority, input views, fixed thresholds and abstentions. Runner review
found and corrected exclusion of credential-flow findings and permissive missing
eligibility flags. It is independent of the scanner author.

SkillFortifyBench's 180 native Claude Markdown examples are external synthetic
fixtures under MIT, with generator labels rather than human-adjudicated ground
truth. Their bodies remain sealed until scanner/runner freeze. They overlap a
MaliciousSkillBench source-disjoint test source; exposure and any subsequent
tuning must be disclosed. Three complete Apache-licensed publisher example
packages supply a separate, explicitly assumed-benign review-burden probe.
Dataset licensing is checked per source. No external comparator is claimed run
until actual comparable outputs exist.

The completed comparison used 180 external native Markdown samples and three
complete publisher packages. Both released and candidate engines selected the
same signals: 8 of 90 upstream malicious labels at review-or-block and 3 at block.
The 90 upstream benign labels had no selected signals but 72 abstentions, so
there is no basis for a zero false-positive-rate claim. This external text probe
does not show a detection gain or establish leadership. The paired multi-file
code cases verify the new mechanism separately. The scoring adapter's exact-
coverage enum correction was reviewed and disclosed after exposure; original
outputs remain preserved and the engine stayed unchanged. See Lena's result
record for class denominators, bounds, provenance and the required next research
cycle with a new held-out source.

## Token guide and focused report views

Measure extracted text characters and UTF-8 bytes. Separate discovery metadata,
main instructions, direct references and optional supporting text. Illustrative
mostly-ASCII text proxies are not tokenizer measurements or guaranteed bounds;
unsuitable language/encoded content has no token estimate. Runtime output, tool
loops, reasoning, caching and host message wrappers remain unassessed.

The lead explicitly requested familiar scopes to reduce clutter while retaining
data: Overview, Security, Structure & process, Standards, Token usage, and
Evidence & coverage. Full exports retain all scopes. Verify keyboard navigation,
responsive layout, actual scan behavior and existing diagram/PNG workflows.

## Completion evidence

Require final-source engine and integration checks, independent security/QA/UI
review, frozen-input baseline/candidate diagnostics with honest denominators,
appropriate regression tests, exact CI/build evidence and protected deployment
acceptance if released. Keep unresolved research opportunities visible instead
of turning this milestone into an unsupported claim of complete skill semantics.
